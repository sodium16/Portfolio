# Zomi — Telegram Bot with Button Interface & Webcmd Dish Scraping

## Project Overview

Zomi is an AI-powered Telegram bot that uses **clickable button interfaces** for all user interactions. Users navigate menus, enter food preferences, and confirm orders with intuitive button clicks instead of typing. The bot scrapes real dishes from Swiggy using webcmd and provides personalized recommendations via Supermemory.

**Key Features:**
- 🔘 **Button-based interface** — All interactions through inline buttons
- 🍽️ **Live Swiggy search** — Real dishes with prices and ratings
- 💾 **Supermemory integration** — Remembers user preferences permanently
- ✅ **One-click ordering** — Confirm orders and checkout with buttons
- 🎯 **Smart onboarding** — Choice buttons for spice level, cuisine, drinks

## Architecture

\\\
User sends /start or clicks button (Telegram)
                    ↓
        telegram/index.js (webhook handler)
                    ↓
        Telegram event: message or callback_query
                    ↓
    For messages → processMessage(userId, userName, text)
    For buttons  → processButtonCallback(userId, userName, callbackData)
                    ↓
    orchestrator/index.js (main logic)
    buttonHandler.js (callback processor)
                    ↓
    Route to appropriate handler based on intent/action
                    ↓
    Generate response with button markup (keyboards.js)
                    ↓
    Send back to Telegram with inline_keyboard
\\\

**Tech Stack:**
- **Telegram Layer** — \src/telegram/\ (webhook, message handling, callback queries)
- **Orchestrator** — \src/orchestrator/\ (message routing, session management)
- **Button System** — \src/telegram/keyboards.js\ (6 reusable button builders)
- **Callback Handler** — \src/orchestrator/buttonHandler.js\ (processes button clicks)
- **Webcmd Layer** — \src/webcmd/\ (Swiggy live scraping)
- **Preferences** — \src/mcp/\ (Supermemory integration)

## Button System

### 6 Keyboard Builders Available

Located in \src/telegram/keyboards.js\:

1. **confirmationKeyboard()** — [✅ Yes] [❌ No]
2. **mainMenuKeyboard()** — [🍽️ Order] [👤 Profile] [❓ Help]
3. **orderConfirmationKeyboard()** — [✅ Confirm] [❌ Cancel] [🔍 Other]
4. **optionsKeyboard(options)** — Dynamic restaurant/dish selections
5. **choiceKeyboard(choices)** — Preset choices (spice, cuisine, drinks)
6. **platformKeyboard()** — [Swiggy] [Zomato]

### Callback Data Format

All buttons use standardized format: \ction:value\

**Examples:**
- \order:confirm\ — Confirm & Checkout button
- \order:other\ — See Other Options button
- \option:2\ — Selected option #2
- \menu:order\ — Order Food button
- \menu:profile\ — My Profile button
- \onboard:spice:🌶️ Medium\ — Spice choice button

## Key Implementation Details

### 1. Message Routing
\\\javascript
// In orchestrator/index.js
switch (classified.intent) {
  case 'GREETING_START': // /start command
  case 'ONBOARDING_ANSWER': // Onboarding responses
  case 'ORDER_FOOD': // Food search
  case 'CONFIRM_ORDER': // Yes to confirmation
  case 'SHOW_PROFILE': // Profile view
  case 'GENERAL_QUESTION': // Help text
}
\\\

### 2. Input Mode for Order Food
When user clicks [🍽️ Order Food] button:
1. Session \inputMode\ set to \WAITING_FOR_DISH_NAME\
2. Bot shows input prompt
3. User types dish name
4. Next message triggers Swiggy search
5. Results shown with confirmation buttons

### 3. Callback Processing
\\\javascript
// In buttonHandler.js
switch (action) {
  case 'order': // [Confirm/Cancel/Other] buttons
  case 'option': // [Restaurant selection] buttons
  case 'menu': // [Order/Profile/Help] buttons
  case 'onboard': // [Choice] buttons in onboarding
  case 'platform': // [Swiggy/Zomato] buttons
  case 'confirm': // [Yes/No] buttons
}
\\\

## Deployment

### Prerequisites
- Node.js v14+
- TELEGRAM_BOT_TOKEN set in .env
- SUPERMEMORY_API_KEY (optional, falls back to local)
- SWIGGY_ACCESS_TOKEN (optional, uses webcmd)

### Steps
\\\ash
# Install dependencies
npm install

# Verify syntax
node -c src/telegram/keyboards.js
node -c src/telegram/index.js
node -c src/orchestrator/buttonHandler.js
node -c src/orchestrator/index.js

# Run tests
node test-buttons.js

# Start bot
npm start
\\\

Bot will be live on Telegram immediately.
